Inside of the Day — Running agents

Each agent is 90%.
Together they hit 50%.

I kept adding agents to my workflow. The total kept getting worse.

How effective each agent stays shaded = coordination tax
The gap is the coordination tax. It grows faster than the agent count. Illustrative shape from my own workflow — not measured values.
Where the tax comes from
1Re-explaining contextEvery agent needs the full briefing, not just the delta.
2Reconciling outputsTwo agents, two answers — a human or a third must merge them.
3Conflicting decisionsA deploys, B reverts. A writes the test, B changes what it tests.
4Duplicated workNeither agent knew the other had already done it.
5Waiting on dependenciesB can’t start until A finishes, and A is waiting on C.
→
The coordination tax is real. More agents is not more throughput — it’s more overhead. Decompose only when the subtasks are truly independent. Same pattern Brooks named in 1975: intercommunication effort grows as n(n−1)/2. Measured on agents, results range from +80.8% on decomposable work to −70.0% on sequential work.
