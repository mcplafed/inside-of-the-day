Agent configuration insight

I switched my coding agent from Sonnet 5 high to Opus 4.8 low.

It got cheaper — and better. Anthropic’s updated BrowseComp chart shows why this can happen.

The lesson

Do not compare model names.
Compare model × effort × harness.

This is one agentic-search benchmark — not a universal coding claim. But it is a clear prompt to benchmark your own agent before paying for more reasoning.
