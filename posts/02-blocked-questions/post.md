# Inside of the Day #2 - Founder questions do not block the system

## Mechanism

A founder-only decision blocks its dependent task. It does not stop independent tasks from progressing. Record unanswered decisions in the work summary so a founder can resolve several questions asynchronously.

## Takeaway

Human attention is for decisions that need a human, not a synchronous dependency for every agent turn.
