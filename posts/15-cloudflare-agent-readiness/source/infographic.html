Inside of the Day · Agent readinessCloudflare · 6 Aug 2026

Check if your site is
AI-agent ready.
Cloudflare can now tell you.

Cloudflare just shipped a hostname diagnostic that scans the path an AI agent uses to enter, find, read and inspect your site.

It is not an AI-ready badge. It is pass / fail / neutral checks with the exact request and response evidence behind each result.
01 · Can it enter?

Access

robots.txt and AI-crawler rules show whether the agent is allowed through the front door.

02 · Can it find + read?

Discovery

XML sitemap, clean Markdown and Content Signals make content machine-readable.

03 · Can it call?

Machine path

API catalog, link headers and login instructions beat guessing at HTML.

04 · Is it agent-native?

Advanced surfaces

OAuth, MCP, A2A, skills index and WebMCP can expose richer paths to inspect.

What I would fix first

Start with boring basics: crawler-readable robots.txt, an XML sitemap and clean Markdown. Then publish an explicit machine path.

The boundary that matters

Discoverable ≠ authorized. A passing diagnostic means an agent can inspect a surface, not that it has permission to act.

COMMERCE: x402 · ACP · UCP · AP2 are informational in the tool at launch — not counted in the readiness score.

Agent discoverability is now a production surface.
