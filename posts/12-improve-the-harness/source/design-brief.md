# Visual brief: Do not bury a long agent session

Create a self-contained editable HTML infographic for LinkedIn.

## Required output

- Exact logical canvas: 1080x1350 px (4:5).
- No external dependencies or network assets.
- Warm parchment background, subtle technical grid, slate ink, restrained terracotta emphasis, semantic muted green.
- Large sans-serif headline and body text; monospace only for small metadata/labels.
- All visual text in English.
- Footer: a thin divider, `github.com/mcplafed/inside-of-the-day` on the left and `@vitalylobachev` on the right.
- Do not include a public post number.
- Design for a 400x500 mobile feed: essential text must remain readable without zooming.

## Copy hierarchy

Eyebrow: `INSIDE OF THE DAY · AGENT OPERATIONS`
Headline: `Don't bury a long agent session.`
Deck: `The final answer is not the only output. Preserve the lessons that make the next session better.`

Central flow, left to right or top to bottom:
`LONG SESSION` -> `RUN /IMPROVE` -> `BETTER HARNESS`

Inside LONG SESSION use four short items:
- failed searches
- conflicting facts
- corrections
- fragile commands

Inside RUN /IMPROVE use four questions:
- What kept recurring?
- What needed correction?
- What should become a script?
- What belongs in a rule or skill?

Inside BETTER HARNESS use four compact outcome chips:
- durable memory
- scoped rules
- tested scripts
- updated skills

Add a visible boundary panel with this exact copy:
`Keep: durable, verified lessons`
`Do not keep: secrets, raw logs, temporary state`

Takeaway block:
`A long session should not end as chat history.`
`It should make the next session better.`

Avoid gradients, illustrations, fake metrics, tiny text, serif display type, and generic SaaS card grids. Use explicit SVG connector paths behind nodes; do not let connectors intersect labels.
