# Typography and information-design specification

Apply this specification to `infographic.html`.

## Typeface system
- One family only: `Arial, FreeSans, Helvetica, sans-serif`.
- The literal `/improve` may use monospace inline as a semantic token. No other monospace.
- Remove Georgia and all other display families.
- Exactly four type sizes: display 92px, lead 30px, body 27px, micro 20px.
- Exactly two weights: 500 and 800.
- Uppercase only for micro text, with one tracking value: .14em.

## One-glance hierarchy
1. Headline: `Don't bury a long agent session.`
2. The vertical spine: `Long session` -> `/improve` -> `Better next session`.
3. One quiet CTA: `Full prompt in the post`.

## Visual rules
- `/improve` is the only dark slate panel.
- Use terracotta only four times maximum: headline accent, slash in `/improve`, outcome bars, CTA accent.
- One emphasis mechanism per element. Do not combine uppercase, bold, tracking, opacity, and accent color.
- No opacity-based emphasis.
- Stage 1 and 3 use the same light container treatment; stage 2 alone is inverted.
- Use bare arrows with no explanatory labels.
- Remove Stage 01/02/03 kickers, eyebrow row, dotted/dashed guardrail panel, all icon illustrations except one optional funnel in `/improve`, arrow labels, and decorative chevrons.
- Move `Tested in Claude Code` to the quiet credits line.
- Replace the guardrail panel with one micro line above the CTA: `Never retained: secrets · raw logs · temporary state`.
- Make the CTA sentence case, not all caps.

The infographic must still explain in full: a long session contains useful work; `/improve` extracts recurring patterns, turns fragile commands into scripts, and stores durable lessons as rules, skills, and memory.
