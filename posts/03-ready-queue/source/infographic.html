Insight of the day 02

When is an autonomous session done?

PR count measures a delivery stage. A ready queue measures remaining opportunity.

Not done

PRs are merging

Previously dispatched work is draining. Useful work can still remain.

Done

The ready queue is empty

There is no safe, actionable issue left to claim or plan.

FEATURE

Before the orchestrator stops:

01 / RE-POLLCheck ready issues, excluding human-blocked work.
02 / PLANCheck whether any needs-plan item can become ready.
03 / HAND OFFGive every in-flight task a clear owner or next step.
04 / SUMMARYList remaining founder decisions separately.
