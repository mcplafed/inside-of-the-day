# Inside of the Day #3 - The ready queue defines done

## Mechanism

Use the ready issue queue as the system's stopping condition. Existing pull requests can drain while agents safely claim, prioritize, and discover further work.

## Takeaway

PR count measures one delivery stage. The ready queue measures remaining opportunity.
